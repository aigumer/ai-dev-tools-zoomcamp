# Household Chores Tool - Project Scope

## Product
- **Type:** Web application
- **Target users:** Couples (2 people)
- **Core problem:** Fairly split and track recurring household chores

## Core Features (MVP)
1. **Chore list + assignment** - Create chores, assign to person, set frequency (daily/weekly/monthly/custom)
2. **Scheduling/calendar** - See what's due when, recurring tasks with due dates
3. **Tracking/completion** - Mark done, view history, streaks

## Tech Stack
- **Backend:** Python + FastAPI
- **Frontend:** React (TypeScript)
- **Database:** PostgreSQL
- **Auth:** Email/password (JWT tokens)
- **Deployment:** VPS (DigitalOcean/Linode/etc.)

## Non-Goals (Post-MVP)
- Notifications (email/push)
- Fairness balancing algorithm
- Shopping list integration
- Mobile apps
- OAuth/social login
